## Одна формула на три задачи

```
Прибыль = Q × (P − V) − F
```

| | Что | Как получить |
|---|---|---|
| **Q** | объём, шт. | дан прямо |
| **P** | цена за штуку | дана прямо (иногда с НДС) |
| **V** | переменные затраты **на штуку** | переменные всего ÷ объём, при котором они даны |
| **F** | постоянные затраты **всего** | сумма постоянных строк, НЕ делить на объём |

`m = P − V` — маржа на единицу.

| Задача | Неизвестное | Формула |
|---|---|---|
| **10** | Q при прибыли 0; затем прибыль при новом Q | `Q = F / m` ; `Прибыль = Q·m − F` |
| **11** | P | `Выручка = переменные всего + F + цель` ; `P = Выручка / Q` |
| **12** | одна статья затрат | `статья = Выручка − цель − все остальные затраты` |

Производные (на случай других формулировок):
```
Объём под целевую прибыль = (F + цель) / m
Допустимые переменные на ед. = P − (F + цель)/Q
Допустимые постоянные = Q·m − цель
```

## Шаг 0 — классификация статей (здесь теряют балл)

Подсказка всегда в скобках. Проверено на вариантах A, B, C — классификация не менялась.

| ПЕРЕМЕННЫЕ | ПОСТОЯННЫЕ |
|---|---|
| основные материалы | прочие материалы **(постоянные затраты)** |
| труд основных производственных рабочих **(сдельная оплата)** | труд прочих работников **(фиксированная оплата)** |
| энергетические затраты **(производственное оборудование)** | энергетические затраты **(постоянные)** |
| **прочие прямые** затраты | амортизация ОС **(линейный метод)** |
| прочие **переменные** косвенные затраты | прочие **постоянные** затраты |

Мнемоника: «сдельная», «прямые» → переменные. «Фиксированная», «амортизация»,
«постоянные» → постоянные.

**Самопроверка:** `V` должна получиться круглым числом (200 / 230 / 410 в трёх вариантах).
Кривая дробь → скорее всего постоянная статья попала в переменные.

## Правила и ловушки

1. **Переменные даны СУММОЙ при конкретном объёме** — обязательно разделить на этот объём.
2. **Постоянные не делим никогда.** При смене объёма они не меняются — в этом смысл задачи.
3. **НДС** чистим только при словах «включая НДС» / «в т.ч. НДС». Прибыль всегда считается
   по цене без НДС; умножение на 1,2 — последним действием и только если просят цену с НДС.
   В варианте C НДС в этих задачах не упомянут вовсе → ответ без всякого умножения.
4. **Отвлекающие данные, которые дают каждый год:**
   - «денежные поступления от покупателей» — деньги к прибыли отношения не имеют;
   - «в т.ч. непроизводственные» — в операционную прибыль входят ВСЕ постоянные,
     разбивка не нужна.
5. `V` в задачах 11–12 дана двумя кусками (материалы + труд) — их надо сложить.
6. Безубыточный объём округляем **вверх**. В вариантах A и B он получается не круглым
   (7 236,5 и 4 963,5), в варианте C — ровно 6 840. Это нормально.
