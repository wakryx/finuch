## Как печатать

PDF: печать «как есть», **двусторонняя, переворот по длинному краю**, масштаб 100 % (не «вписать в страницу»).

Из HTML: открыть в браузере → Печать → A4, поля «по умолчанию», масштаб 100 %,
включить «печать фона» (иначе пропадут заливки таблиц и рамки блоков).

## Как править читлист

Блоки — это `<div class="box">` внутри `<div class="col">`. Правится содержимое,
а раскладка по трём колонкам пересчитывается автоматически:

```
python3 03-читлист/_layout.py          # мерит боксы в браузере и заново делит на 3 колонки
```
Скрипт печатает заполнение каждой колонки в % от страницы. Держать ≤ 100 %:
выше — контент уедет на третью страницу. Порядок блоков не меняется,
колонки нарезаются только по границам блоков.

Пересобрать PDF:
```
/opt/pw-browsers/chromium_headless_shell-1194/chrome-linux/headless_shell \
  --no-sandbox --headless --print-to-pdf=03-читлист/читлист-v2-НА-ПЕЧАТЬ.pdf \
  --no-pdf-header-footer file://$PWD/03-читлист/читлист-v2.html
```
