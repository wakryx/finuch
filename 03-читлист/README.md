## Как печатать

PDF: печать «как есть», **двусторонняя, переворот по длинному краю**, масштаб 100 % (не «вписать в страницу»).

Из HTML: открыть в браузере → Печать → A4, поля «по умолчанию», масштаб 100 %,
включить «печать фона» (иначе пропадут заливки таблиц и рамки блоков).

- **Единая нумерация** — по официальным «Темам к экзамену». Сверху таблица перевода
  на нумерацию 20- и 27-задачных вариантов.

  продукты; тема 17 — перепутанные запасы; тема 8 — совпадающие ответы).
- Добавлены «домашние правила» курса: НЗП = 50 %, FIFO, НДС в теме 13.
- Тема 3 (консолидация, 4 балла) расписана с готовым примером.
- Темы 18–20 — одна универсальная схема цепных подстановок на все 5 факторов
  вместо одной формулы на номер.
- Добавлена таблица классификации статей затрат для CVP.
- Бонусом: ОФР «по характеру расходов» и ОДДС косвенным методом — их нет в «Темах»,
  но они были во всех трёх вариантах прошлых лет.
