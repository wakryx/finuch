4. ПРОИЗВОДСТВЕННАЯ И МАРЖИНАЛЬНАЯ СЕБЕСТОИМОСТЬ (2 б.) Производственная (absorption) на ед. = прямые мат. + прямой труд + ПЕРЕМ. произв. косвенные/ед + ПОСТ. произв. косвенные/ед Маржинальная на ед. = прямые мат. + прямой труд + ПЕРЕМ. произв. косвенные/ед

Разница = постоянные производственные на единицу. Непроизводственные не входят никогда.

5. ПОЛНОЕ ПОГЛОЩЕНИЕ vs МАРЖИНАЛЬНЫЙ (4 б.) 1) База X, база Y → доли (база из условия!) 2) ПрямыеX = выпуск·(мат+труд) 3) ABSX = Прямые + (перем+пост произв.)·доля MARGX = Прямые + перем.произв.·доля 4) себест./ед = сумма / ВЫПУСК (не продажи!) 5) Выручка = продажи · цена ПРИБЫЛЬ absorption: Выручка − Σ(продажи·себест.ед ABS) − ВСЕ непроизводственные ПРИБЫЛЬ marginal: Выручка − Σ(продажи·перем.себест.ед) − ВСЕ пост. произв. − ВСЕ непроизв.

✅ КОНТРОЛЬ:

Пabs − Пmarg = Σ Δзапасаi · (пост.произв.i/выпускi) Δзапаса = произведено − продано
  • Запас вырос → absorption даёт прибыль БОЛЬШЕ.
  • Базой бывает: прямые материалы / прямой труд / «прямые затраты — всего». Читать!
6. ПОЗАКАЗНОЕ (1 б.) Ставка косв. = все косвенные / вся база Косвенные заказа = ставка · база заказа Себестоимость = материалы + труд + косвенные Прибыль = цена заказа − себестоимость

Труд заказа = Σ(люди × часы × ставка).

База меняется! Встречались: количество курсов (÷18, ÷20), численность слушателей (÷450), часы. Берите ту, что названа.

Если цена «включая НДС» → сначала /1,2.

Поток: НЗПн + запуск = ГП + НЗПк

Степень завершённости НЗП не дана → 50 %.

A. НЗПн = 0 (простой случай):

ЭЕресурс = ГП + НЗПк · %вложено ставка = затратыресурс / ЭЕресурс уд.себест.ГП = Σ ставок уд.себест.НЗП = Σ(ставка · %вложено)

B. Есть НЗПн → FIFO:

ЭЕ = доработка НЗПн + начато&закончено + НЗПк доработка = НЗПн · (100% − %вложенон) начато&зак. = ГП − НЗПн НЗПк = НЗПк · %вложенок ставка = затраты ПЕРИОДА / ЭЕ Себест. ГП = стоимость НЗПн (вся!) + Σ(доработка · ставка) + (ГП−НЗПн) · Σставок Себест. НЗПк = Σ(НЗПк·%вложено·ставка)

✅ КОНТРОЛЬ: Себест.ГП + Себест.НЗПк = стоимость НЗПн + все затраты периода. Не сходится — ошибка в ЭЕ. Материалы и труд считать раздельно, у них разные %.

9. КОСВЕННЫЕ / ABC (2 б.) Традиционный: ставка = ВСЕ косвенные / вся база косв.X = ставка · базаX себест.X = прямыеX + косв.X ABC: «прочие» → по общей базе (как выше) остальные пулы → по операциям: стоим.операции = пул / ВСЕГО операций косв.X = стоим.операции · операцииX

РЕШЕНИЯ 13–16: общий принцип

Считаем только ИЗМЕНЕНИЕ прибыли относительно текущего варианта.

Игнорировать всегда: прошлые (необратимые) затраты · затраты совместного процесса до точки разделения · распределённые неустранимые постоянные.

Ответ отрицательный → писать знак минус.

13. ПОСЛЕДУЮЩАЯ ОБРАБОТКА (2 б.) доп.маржа/ед = цена ПОСЛЕ − цена В ТОЧКЕ − доп. переменные/ед ΔПрибыли = объём · доп.маржа/ед − доп. постоянные Безубыт. объём = доп.постоянные / доп.маржа/ед
  • Затраты совместного процесса — не брать.
  • Ставки НДС во вводной — отвлекающий факт, цены уже без НДС.
  • Если доп.маржа ≤ 0 — обработка невыгодна при любом объёме.
14. ПОКУПАТЬ ИЛИ ПРОИЗВОДИТЬ (2 б.)

База сравнения — «сейчас покупаем».

экономия/ед = цена покупки − перем. производства/ед ΔПрибыли = объём · экономия/ед − постоянные производства Безубыт. объём = постоянные производства / экономия/ед

Ниже безубыточного объёма выгоднее покупать.

Если экономия/ед < 0 — производить невыгодно всегда.

15. ПРЕКРАТИТЬ / ЗАМЕНИТЬ (2 б.)

Шаг 1 — разложить постоянные (здесь чаще всего ошибаются):

неустранимыеi = ВСЕГО неустранимых · доляi по БАЗЕ (база: пропорц. переменным ИЛИ пропорц. выручке — из условия!) устранимыеi = постоянныеi − неустранимыеi ✅ проверка: Σ неустранимых = сумма из условия

Шаг 2:

маржаi = выручкаi − переменныеi ПРЕКРАЩЕНИЕ X: ΔП = − маржаX + устранимыеX ЗАМЕНА Y на W: ΔП = − маржаY + устранимыеY + маржаW − доп.постоянныеW

Распределённые неустранимые постоянные экономией НЕ являются. Ответ может быть и «+» (закрыть выгодно) — не подгонять.

16. ЛИМИТИРУЮЩИЙ РЕСУРС (1 б.) маржа/ед = цена − ПЕРЕМЕННАЯ составляющая маржа/ресурс = маржа/ед / ресурс на ед ← ранжируем ПО ЭТОМУ
  1. Считаем маржу на 1 ед. ресурса для всех
  2. Сортируем по убыванию
  3. Лучшему даём весь спрос, вычитаем часы
  4. Следующему — сколько влезет
  5. Последний = min(спрос; остаток ресурса / ресурс на ед)

НЕ ранжировать по марже на штуку. Постоянные — распределённые, неустранимые → игнорировать. Выпуск никогда не больше спроса.

17. ЛОВУШКИ (перечитать перед сдачей)
  • НДС — не доход и не расход. В прибыль только суммы без НДС.
  • «Начислено» → ОФР и ББ, но НЕ ОДДС.
  • Амортизация — расход без движения денег.
  • Себестоимость на единицу делим на ВЫПУСК, а не на продажи.
  • Absorption включает постоянные производственные в запасы, marginal — нет.
  • Совместные затраты до точки разделения — нерелевантны.
  • Неустранимые распределённые постоянные — не экономия при закрытии.
  • Лимит ресурса: ранжировать по марже на ресурс, не на штуку.
  • Цепные подстановки: предыдущие факт, последующие план.
  • Единицы: руб / тыс.руб / млн.руб — привести к тем, что просят.
  • Знак «минус» при ухудшении писать обязательно.
  • Один и тот же расчёт может иметь разные вопросы — дочитывать.
ЕСЛИ ОТВЕТ ВЫГЛЯДИТ СТРАННО
  • ГП + НЗПк ≠ затратам → ошибка в эквивалентных единицах.
  • Σ распределённых косвенных ≠ пулу → ошибка в базе.
  • Σ неустранимых ≠ сумме из условия → ошибка в долях.
  • Пabs − Пmarg ≠ Δзапас·пост/ед → ошибка в одном из методов.
  • Консолидация не сходится → проверь, убрал ли инвестицию в дочку.
