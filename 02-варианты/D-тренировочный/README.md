# Вариант D — тренировочный

Составлен 16.09.2026 специально под покрытые темы. Числа новые, сюжеты и формулировки
вопросов — как в вариантах прошлых лет.

| Файл | Что это |
|---|---|
| `УСЛОВИЯ.md` | Задания. 20 баллов по покрытым темам, остальные номера помечены «пропустить» |
| `ОТВЕТЫ.md` | Ответы и разбор. **Открывать только после решения** |

## Что здесь специально подложено

Каждая задача несёт ту ловушку, на которой уже терялись баллы:

| № | Ловушка |
|---|---|
| 6 | «включая НДС 20 %» + база «численность слушателей» (умножать на 36, не на 1) |
| 8 | во втором вопросе меняется и трактовка побочного продукта, и база |
| 10 | классификация статей: энергия оборудования — переменная, линейная амортизация — постоянная |
| 11 | ответ просят **включая НДС** → последний шаг ×1,2 |
| 12 | ответ на единицу; вычесть труд и прочие переменные |
| 13 | два вопроса про **разные** продукты; у X потери 5 % массы |
| 14 | распределённые постоянные 60 руб./шт. в расчёт не идут |
| 15 | устранимые = постоянные продукта − его доля неустранимых (не наоборот) |
| 16 | ранг по марже на машино-час, не на штуку; остаток часов перевести в штуки |
| 17 | довести до **рублей**; цены реализации — отвлекающие данные |
| 18–20 | три разных фактора: норма, ставка, объём. Ответы в **тыс. руб.**, в 20-й — со знаком «минус» |

## Как прогонять

1. Засечь 2 часа, читлист под рукой, ответы — отдельным списком «номер — ответ».
2. Перед каждой записью три вопроса: **что спросили / в каких единицах / про какой продукт**.
3. Единицы написаны в скобке в конце вопроса — читать её последней.
4. Сверяться с `ОТВЕТЫ.md` только после того, как записал всё.
