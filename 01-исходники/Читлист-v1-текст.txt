КОНСОЛИДАЦИЯ №3
Дочка - контроль: в консолидированный ББ включить 100% активов и обязательств дочерней, не инвестицию в нее.
Зависимая - существенное влияние: метод долевого участия, одной строкой "финвложение/инвестиция".
Гудвилл = цена инвестиции - доля материнской в чистых активах дочки на дату покупки.
ЧА дочки = Активы - Обязательства = капитал.
Доля меньшинства = доля миноритариев x чистые активы дочки на отчетную дату (если полная консолидация).
Инвест. в зависимую = цена + доля в прибыли после покупки - дивиденды.

№4-5: СЕБЕСТОИМОСТЬ ПРОДУКТОВ
Прямые на ед.: материалы = норма x цена; труд = часы x ставка. Для всех изделий: на ед. x объем производства.
Косвенные по базе: ставка = общий пул / общая база; на продукт = ставка x база продукта; на ед. = сумма / выпуск.
Произв. себест. продукта = прямые материалы + прямой труд + производственные косвенные.
Маржинальная прибыль = Выручка - переменные затраты.
Операц. прибыль = Марж. прибыль - постоянные затраты.
№4: продукты X/Y, себестоимость X по полной/маржинальной методике и прибыль от продаж X. База - прямые материалы. №5:
учебный курс, доход без НДС = цена с НДС/1,2; прибыль = доход - переменные - релевантные постоянные.
ПОЗАКАЗНОЕ №6
Труд заказа = Σ(люди x часы x ставка).
База заказа = Σ(люди x часы) или другая база из условия.
Ставка косвенных = все косвенные затраты / вся база организации.
Косвенные заказа = ставка косвенных x база заказа.
Себест. заказа = материалы + труд + косвенные заказа.
Прибыль заказа = цена заказа - себест. заказа.
Если заказ выполняется за месяц - все затраты заказа относятся на него; общие косвенные распределяются только по базе.
ПОПРОЦЕССНОЕ №7
Физический поток: НЗПн + запуск = ГП + НЗПк.
Экв. ед. ресурса = ГП x 100% + НЗПк x % завершенности (если НЗПн=0, средняя простая).
Ставка ресурса = затраты ресурса / экв. ед. ресурса.
Себест. ГП = ГП x Σставок ресурсов.
Себест. НЗПк = Σ(НЗПк x %ресурса x ставка ресурса).

СОВМЕСТНЫЕ ПРОДУКТЫ №8, №13
Распределение совместных затрат: только до точки разделения и только на основные продукты. Побочный продукт C -
отдельно.
Ставка процесса = затраты процесса / база основных продуктов (вес, объем, стоимость продаж).
Себест. продаж осн. продукта = ставка x объем реализованного.
Чистый доход побочного = выручка C - затраты продажи C.
Вариант 1: чистый доход C как прибыль: валовая = выручка A+B - СП A+B + чистый доход C.
Вариант 2: доход C уменьшает процесс: распределять (затраты процесса - чистый доход C).
Последующая обработка
Результат = объем x (цена после - цена в точке - доп. переменные на ед.) - доп. постоянные.
Безубыточный объем = доп. постоянные / (цена после - цена в точке - доп. переменные на ед.). Совместные
затраты до разделения нерелевантны.
КОСВЕННЫЕ И УЧЕТ ПО ОПЕРАЦИЯМ №9
Традиционный метод: все косвенные в один пул, ставка = косвенные всего / база всего.
Косвенные продукта = ставка x база продукта; себест. = прямые + косвенные.
Учет по видам деятельности: часть косвенных остается традиционно, остальные по операциям.
Стоимость операции = пул activity / кол-во операций всего.
Косвенные по операции продукта = стоимость операции x операции продукта.

БЕЗУБЫТОЧНОСТЬ №10-12
Переменные на ед. = переменные затраты при данном объеме / объем. Постоянные не делить для маржи.
Маржа на ед. = цена - переменные на ед.; доля маржи = маржа на ед. / цена.
Прибыль = объем x маржа на ед. - постоянные.
Безубыточный объем = постоянные / маржа на ед.. Для целевой прибыли: объем = (постоянные + целевая
прибыль)/маржа на ед..
Цена для цели = (переменные всего + постоянные + целевая прибыль) / объем.
Искомые переменные = объем x цена - постоянные - целевая прибыль; если ищут материал на ед.: разделить
остаток на объем.
№10: безубыточность и прибыль при другом объеме. №11: цена с НДС для целевой прибыли - сначала цена без НДС, потом x1,2.
№12: найти удельные материалы при цели и цене с НДС - цену очистить /1,2.

БЕЗУБЫТОЧНОСТЬ: ОБРАТНЫЕ ФОРМУЛЫ
Выручка = цена x объем; переменные = переменные на ед. x объем; маржа = (цена - переменные на ед.) x
объем.
Объем для цели = (постоянные + целевая прибыль)/(цена - переменные на ед.).
Цена для цели = переменные на ед. + (постоянные + целевая прибыль)/объем.
Допустимые переменные на ед. = цена - (постоянные + целевая прибыль)/объем.
Допустимые постоянные = объем x (цена - переменные на ед.) - целевая прибыль.
Цена с НДС для прибыли: PбезНДС=PсНДС/1,2; ответ с НДС: PбезНДС x 1,2.
MAKE OR BUY №14
База - "покупать". Оценивать переход к производству.
Экономия покупки = объем x цена покупки.
Затраты производства = объем x переменные производства + устранимые/доп. постоянные.
Изменение прибыли = объем x (цена покупки - переменные производства на ед.) - постоянные производства.
Безубыточный объем = постоянные производства / (цена покупки - переменные производства на ед.), если
марж. эффект > 0.
Неустранимые общие постоянные игнорировать. Если переменные производства выше цены покупки и есть постоянные -
производить невыгодно при любом объеме.
ПРЕКРАЩЕНИЕ/ЗАМЕНА №15
Прекратить продукт: потеря маржинальной прибыли продукта + экономия устранимых постоянных.
Изменение прибыли = -маржа продукта + устранимые постоянные.
Распределенные общецеховые постоянные, которые остаются, не считать экономией.
Заменить на W: эффект прекращения старого + маржа нового - доп. постоянные нового.
Изменение прибыли = -маржа старого + устран. постоянные старого + маржа нового - доп. постоянные
нового.
Маржа = выручка - переменные затраты.
№15: изменение годовой прибыли при прекращении X и при замене Z на W; знак минус обязательно, если ухудшение.
ЛИМИТИРУЮЩИЙ РЕСУРС №16
Маржа на ед. = цена - переменные на ед..
Маржа на ресурс = маржа на ед. / ресурс на ед..
Алгоритм: 1) посчитать маржу/час для A,B,C; 2) упорядочить по убыванию; 3) производить до спроса лучший продукт; 4)
остаток ресурса отдать следующему; 5) последний = min(спрос, ресурс остаток / ресурс ед.).
Если ресурса хватает на весь спрос: выпуск = спрос. Если маржа на ед. отрицательная - продукт не производить, даже если есть
спрос.
БЮДЖЕТИРОВАНИЕ №17
Продажи шт. x цена = выручка.
Запас к.п. = % x продажи след. месяца.
Закупки шт. = продажи шт. + запас к.п. - запас н.п..
Закупки руб. = закупки шт. x цена закупки.
Использование материалов = выпуск продукта x норма материала.
Закупка материала = использование + запас к.п. - запас н.п..

ОТКЛОНЕНИЯ №18-20
Цепные подстановки: для Y = x1 x2 x3 ... влияние xi = (факт предыдущих факторов) x (xiф - xiп) x (план следующих

факт x (ставка факт - ставка план).

Положительное отклонение затрат = факт затрат больше плана (хуже). Отрицательное = экономия.

ЕСЛИ УСЛОВИЕ НЕПОЛНОЕ
Дана сумма с НДС -> сначала база и НДС. Дана оплата, но не продажа
-> восстановить через ДЗ. Дана себестоимость, но не закупки ->
восстановить через запасы. Даны ОС начало/конец -> учесть
поступления, выбытие, амортизацию. Даны проценты по кредиту ->
ОФР расход, ОДДС текущий платеж, ББ задолженность если не
оплачено. Дана предоплата -> это аванс, не доход/расход до поставки.
Дана скидка/возврат -> уменьшает выручку или закупки. Дана курсовая
разница -> доход/расход, деньги только если был платеж.

7-9: ПРОВЕРКИ
Попроцессное: сумма себест. ГП + НЗПк должна равняться затратам в процессе (с учетом НЗПн).

10-13: ТИПОВЫЕ ЛОВУШКИ
Безубыточность: постоянные затраты не меняются при новом объеме, переменные пересчитываются через переменные
на ед.
Цена с НДС: прибыль считать по цене без НДС; если ответ про цену "включая НДС", в конце умножить на 1,2.
Целевая прибыль: прибыль уже после покрытия всех постоянных, поэтому постоянные + целевая прибыль в числителе.
Последующая обработка: затраты совместного процесса уже понесены до точки разделения, не включать в сравнение.
Если доп.маржа ед. = 0 и доп. постоянные > 0 -> последующая обработка всегда хуже.

Пример: продажи α 8500, запас нач. 120, запас кон. 130; β продажи 10000, запас нач. 180, запас кон. 200. Нормы M1: α 10,

1Выпуск α=8500+130-120=8510. Выпуск β=10000+200-180=10020.
2Использование M1=8510×10+10020×5=135200. M2=8510×1+10020×8=88670.
3Если M1 нач. 20200, кон. 25000, цена 4: закупка=(135200+25000-20200)×4=560000.
4Если M2 нач. 12200, кон. 15000, цена 20: закупка=(88670+15000-12200)×20=1829400. Всего закупок=2389400.
Поступления: если продажи мая 7128, апреля 6500, оплата 50% сразу, 30% через 0,5 мес, то май=0,5×7128+0,3×6500+0,2×март.
18. ОТКЛОНЕНИЕ: ОБЪЕМ X ТРУДОЕМКОСТЬ X СТАВКА
Пример: переменные косвенные план 54900; объем план 30500; план 0,45 ч/ед.; объем факт 28000; факт часы 13440.
1План часы=30500×0,45=13725. План ставка=54900/13725=4.
2Факт часы/ед.=13440/28000=0,48.
3Влияние трудоемкости=28000×(0,48-0,45)×4=3360.
4Плюс означает перерасход: фактическая трудоемкость выше плановой на 0,03 ч/ед.
19. ОТКЛОНЕНИЕ: ЧАСЫ НА ЗАКАЗ
Пример: косвенные план 10098; заказы план 660; план 3,4 ч/заказ; факт 620 заказов; факт часы 2170.
1План часы=660×3,4=2244. План ставка=10098/2244=4,5.
2Факт часы/заказ=2170/620=3,5.
3Влияние часов/заказ=620×(3,5-3,4)×4,5=279.
4Плюс 279 - перерасход, потому что на заказ ушло больше часов.
20. ОТКЛОНЕНИЕ: ОБЪЕМ ОЧИСТКИ
Пример: план химиката 0,45 т на 50000 л очистки; цена 17 тыс./т; план очистки 2,0 млн л, факт 2,1 млн л.
1План расход=0,45/50000 т на литр.
2Доп. объем очистки=2100000-2000000=100000 л.
3Влияние=100000×0,45/50000×17=15,3 тыс. руб.
4Плюс 15,3 - затраты выросли только из-за большего объема очистки при плановой норме и цене.

17-20: ФОРМУЛЫ ПОДСТАНОВКИ
Товарный бюджет: запасы к.п. = % x продажи след.; закупки = продажи + запасы к.п. - запасы н.п.
Материальный бюджет: потребность = выпуск x норма; закупка = потребность + запас к.п. - запас н.п.
Гибкий бюджет затрат: переменная часть x факт объем/план объем + постоянная часть.
Цепь 2 факторов: y=ab; Δa=(aф-aп)bп; Δb=aф(bф-bп).
Цепь 3 факторов: y=abc; Δa=(aф-aп)bпcп; Δb=aф(bф-bп)cп; Δc=aфbф(cф-cп).
Для задач 18-20 сначала восстановить недостающие удельные показатели: ставка = сумма/база, норма = ресурс/объем.

ГОТОВЫЕ ВЫВОДЫ
Изменение прибыли положительное -> альтернатива выгодна на эту
сумму. Изменение отрицательное -> прибыль уменьшится,
альтернативу не принимать. Безубыточный объем меньше ожидаемого
-> решение выгодно при заданном объеме. Безубыточный объем
больше спроса -> решение не окупится. Маржа на ресурс выше ->
продукт идет раньше в производственный план. Факт затрат больше
плана -> неблагоприятное отклонение. Факт выручки/прибыли больше
плана -> благоприятное отклонение. Если итог в тыс. руб., все
рублевые величины привести к тыс. до подстановки.
МИНИ-ПРОВЕРКИ ЧИСЕЛ
Цена 600 с НДС -> без НДС 500, НДС 100. Маржа: цена 500,
переменные 320 -> маржа 180; постоянные 90000 -> безубыт. объем
500 шт. Целевая прибыль 27000 -> объем=(90000+27000)/180=650 шт.
Полный метод: постоянные произв. 60000/3000=20 на ед.; если запас
вырос на 400 шт., прибыль полного метода выше маржинального на
8000. Покупать/производить: покупка 80, переменные производства 55,
постоянные 30000 -> безубыт. объем 1200. Лимит: маржа 90, ресурс 3 ч
-> 30/ч; маржа 140, ресурс 7 ч -> 20/ч, первый продукт приоритетнее.
Отклонение: план 2 кг×50, факт 2,2 кг×48 -> норма +10, цена -4,4 на ед.
КОГДА ОТВЕТ ВЫГЛЯДИТ СТРАННО
Отрицательная себестоимость невозможна -> перепутаны начальные/
конечные запасы. НДС попал в прибыль -> ошибка, прибыль без НДС.
ОДДС изменился от амортизации -> ошибка, амортизация без денег.
Закрытие продукта улучшает прибыль больше всей маржи ->
проверить, не взяты ли неустранимые постоянные как экономия.
Безубыт. объем отрицательный -> маржа на ед. отрицательна, проект
не окупается обычной формулой. В лимите произведено больше
спроса -> ограничить спросом. В попроцессном сумма ГП+НЗП не
равна затратам -> ошибка ставок/экв.ед.
СВОДНЫЙ АЛГОРИТМ РЕШЕНИЯ
Проводки: актив увеличился -> Дт; актив уменьшился -> Кт; обязательство увеличилось -> Кт; доход -> Кт; расход -> Дт.
Калькулирование: прямые затраты -> ставка распределения -> косвенные -> удельная себестоимость -> прибыль/
запасы.
Безубыточность: привести задачу к цене, переменным на ед., марже на ед., постоянным, объему; неизвестное найти из
прибыль=объем×(цена-переменные ед.)-постоянные.
Релевантные решения: считать только изменение прибыли относительно исходного сценария.
Отклонения: восстановить плановую ставку/норму, затем применить цепную подстановку.
